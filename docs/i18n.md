# Internacionalización (i18n)

Idiomas soportados: **español (es)**, **inglés (en)**, **ruso (ru)**.

## Activar idioma

En `public/config.json`:

```json
{ "language": "ru" }
```

Valores válidos: `"es"` (default), `"en"`, `"ru"`.

## Arquitectura

### `src/i18n/translations.ts`

Diccionario de textos de la UI (etiquetas fijas, no contenido de config):

```ts
export type Locale = 'es' | 'en' | 'ru';
export type LocalizedString = string | Partial<Record<Locale, string>>;

export const translations = {
  es: {
    eyebrow: '✈️ La aventura comienza en...',
    countdown: { days: 'Días', hours: 'Horas', minutes: 'Minutos', seconds: 'Segundos' },
    countdownAriaLabel: 'Cuenta regresiva para el viaje',
    departure: 'Salida',
  },
  en: {
    eyebrow: '✈️ The adventure begins in...',
    countdown: { days: 'Days', hours: 'Hours', minutes: 'Minutes', seconds: 'Seconds' },
    countdownAriaLabel: 'Trip countdown',
    departure: 'Departure',
  },
  ru: {
    eyebrow: '✈️ Приключение начинается через...',
    countdown: { days: 'Дней', hours: 'Часов', minutes: 'Минут', seconds: 'Секунд' },
    countdownAriaLabel: 'Обратный отсчёт до поездки',
    departure: 'Отправление',
  },
};
```

### `src/i18n/localize.ts`

```ts
export function localize(value: LocalizedString, locale: Locale): string {
  if (typeof value === 'string') return value;
  return value[locale] ?? value['es'] ?? value['en'] ?? value['ru'] ?? '';
}
```

Fallback: idioma activo → es → en → ru → string vacío.

## Campos localizables en config.json

| Campo | Tipo |
|---|---|
| `tripName` | `LocalizedString` |
| `subtitle` | `LocalizedString` |
| `completionMessage` | `LocalizedString` |

Estos campos aceptan string plano (backward-compatible) o objeto con traducciones:

```json
"tripName": "Viaje a Cancún"
// o bien:
"tripName": { "es": "Viaje a Cancún", "en": "Cancún Trip", "ru": "Поездка в Канкун" }
```

## Agregar un nuevo idioma

1. Añadir la nueva locale a `Locale` en `translations.ts`:
   ```ts
   export type Locale = 'es' | 'en' | 'ru' | 'fr';
   ```

2. Agregar las traducciones UI al objeto `translations`:
   ```ts
   fr: {
     eyebrow: '✈️ L\'aventure commence dans...',
     countdown: { days: 'Jours', hours: 'Heures', minutes: 'Minutes', seconds: 'Secondes' },
     countdownAriaLabel: 'Compte à rebours du voyage',
     departure: 'Départ',
   }
   ```

3. Actualizar `config.json`:
   ```json
   { "language": "fr" }
   ```

TypeScript reportará error en compilación si falta alguna traducción (el tipo `satisfies` lo garantiza).
